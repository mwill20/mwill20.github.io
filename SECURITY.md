# Security

## Scope

This repository is a static personal website served by GitHub Pages. It contains HTML,
CSS, one JavaScript file, and an SVG favicon.

- No server-side code runs. GitHub Pages serves the files as-is.
- No user input is collected or processed. There are no forms, no comments, no search.
- No analytics, tracking, or third-party scripts are loaded.
- No secrets, tokens, or credentials exist in this repository.
- The only external resources are Google Fonts stylesheets (fonts.googleapis.com and
  fonts.gstatic.com). The page renders in system fonts if they are blocked.

## Content integrity

The ledger line in the page footer is illustrative in this version. A tamper-evident,
Action-generated ledger is planned for the GitHub profile repository and will be
documented there when it exists.

## Reporting

If you find a problem with this site (a broken link, an incorrect claim, an
accessibility issue, or a security concern), open an issue in this repository or email
mwill.itmission@gmail.com. There is no bug bounty.
